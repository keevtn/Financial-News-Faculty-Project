# Financial News Faculty Project
## Introduction
This project is a planned Python-based platform for monitoring financial news and market-related social sentiment in near real time. Its goal is to bring together ticker data, financial headlines, and public market discussion into one place so that stocks can be ranked and reviewed more efficiently.

## Project Overview
The intended system will collect data from reputable financial and regulatory sources such as newswires, financial media, market platforms, and public filings, with RSS feeds used where available and scraping considered where necessary. It is also expected to incorporate a Finviz screener CSV as a starting point for ticker selection and eventually present ranked results in a dashboard inspired by stock screening tools, including sentiment and message-density views.

This repository currently serves as an initial description of the project scope and direction, as the implementation will follow in the upcoming weeks.
